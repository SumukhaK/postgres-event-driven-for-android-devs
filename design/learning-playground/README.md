# Postgres Lab learning playground mockups

Open editorial.html, studio.html, or guided.html directly in a modern browser. No install or server is needed. All three show the same Chapter 08 stock-concurrency exercise from this repository, with different learning layouts.

## Directions

- **Editorial learning lab:** reading-first lesson with a persistent course rail and coach.
- **Developer studio:** dark, code-first workspace with query output and compact contextual help.
- **Guided learning path:** warm milestone view with a clear next step and graduated support.

Run, complete, sign-in, provider, and help interactions are local previews. The SQL is not executed, progress is not stored or synced, and no account or AI provider is contacted. The account preview includes a conditional ChatGPT sign-in label and email fallback. AI provider settings are separate and show OpenCode, OpenAI, and Anthropic choices with cost and authorization disclosures; do not enter credentials in this mockup.

Screenshots are in ../../screenshots/.

To regenerate the 1440×1000 offline preview exports on Windows, run render-screenshots.ps1 from this folder. They are visual comps for the matching HTML concepts; the browser-only interactions remain in the HTML pages.
